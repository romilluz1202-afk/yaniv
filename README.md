# יניב 🎴 — משחק קלפים מרובה משתתפים

משחק יניב מלא לשחק עם חברים דרך לינק. שרת authoritative (מונע רמאות, מבטיח חוקים), לקוח מובייל-first בעברית RTL, עיצוב קלאסי (לבד ירוק + זהב), אנימציות חלקות וקצב מהיר.

## איך משחקים
1. פותחים חדר → מקבלים קוד בן 4 תווים (למשל `8CLQ`).
2. משתפים את הקוד/לינק בוואטסאפ.
3. כל חבר מזין שם ונכנס — עד 4 שחקנים.
4. המארח לוחץ "התחל משחק".

## חוקים
- 5 קלפים לכל שחקן. אס=1, 2–10 כערכם, J/Q/K=10, ג'וקר=0.
- בתור: זורקים **קלף בודד / סט / רצף**, ומושכים מהקופה או מקצה הזריקה הקודמת.
- **יניב** כשהיד ≤ 7 (ניתן לשנות ל-5). אם למישהו יש ≤ ממך → **אסף** (+30 עונשין).
- מפסידים ב-200 נק'. בונוס: ניקוד מדויק 100→50, 200→100.

## הרצה מקומית
```bash
npm run install:all     # מתקין server + client
npm run dev             # שרת (2567) + לקוח (5173) במקביל
# פותחים http://localhost:5173 בכמה טאבים/מכשירים
```

## בדיקות
```bash
npm test                # בדיקות יחידה למנוע (Vitest)
npm run e2e             # בדיקת e2e: 2 שחקנים משחקים סיבוב מלא (דורש שרת רץ)
```

## Deploy ל-Render
הפרויקט כולל `render.yaml`. מחברים את ה-repo ל-Render (Blueprint) → נוצר service יחיד שמגיש את הלקוח הבנוי + שרת ה-WebSocket על אותו URL.

## ארכיטקטורה
```
shared/   — טיפוסים משותפים
server/   — Colyseus (authority) + Express; engine/ = לוגיקת משחק טהורה (נבדקת)
client/   — React + Vite + framer-motion; RTL; net/ = חיבור Colyseus
```
- **מנוע** (`server/src/engine/`) — פונקציות טהורות: חפיסה, צירופים, ניקוד, סיבוב. 31 בדיקות.
- **חדר** (`server/src/rooms/YanivRoom.ts`) — מאמת כל פעולה, שולח ידיים פרטיות בלבד, reconnection, טיימר תור.
- **לקוח** — מסכי Home / Lobby / Table + שכבות יניב/אסף/תוצאות/סיום.
